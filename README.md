## 周记与自检

按 [[Claude计划]] 的安排，**每周日**花 4 小时：补进度 → 复盘 → 提交 GitHub → 写周记。

- **模板**：[[周记模板]]（内含「每周自检三问」）
- **存放**：`周记/W01 周记.md`、`周记/W02 周记.md` …… 依此类推
- **用法**：在 `周记/` 下新建空笔记 → `Ctrl+P` → 输入「模板」→ 选「插入模板」→ 选 `周记模板`
  （Obsidian 的模板文件夹已配置为 `模板/`）
- **已建**：[[W01 周记]]

**每周自检三问**（摘自 [[Claude计划]]）：

1. 本周的代码我能不看资料重写一遍核心部分吗？
2. 我遇到的最大障碍是什么？是否拖了超过一天？
3. 本周产出有没有提交到 GitHub？

> 如果任何一周连续两次「不能」，就当周放慢节奏，补基础。
